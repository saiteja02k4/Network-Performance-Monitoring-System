# Network Performance Monitoring System

Developed a network consisting of 25 client systems using Cisco Packet Tracer.

- 2 Switches
- Server
- 25 PCs

- Network Connectivity Testing
- Troubleshooting Scenarios

## Technologies

- Networking Fundamentals

## Key Learnings
- IP Addressing

- DHCP
- DNS
- Routing and Switching
- Network Troubleshooting

## Testing
- Ping-based connectivity verification
- DHCP lease validation
- DNS name resolution testing
